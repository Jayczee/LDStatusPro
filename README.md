# LDStatus Pro

本仓库是 LDStatus Pro 的 fork。原版功能和使用文档请见[原仓库 caigg188/LDStatusPro](https://github.com/caigg188/LDStatusPro)。

### v3.9.0.12

本 fork 基于此版本新增了**自动阅读帖子回复**功能，代码在[自动阅读分支](https://github.com/Jayczee/LDStatusPro/tree/feat/topic-reply-reader)。打开帖子后，页面会自动向下滚动浏览回复，插件面板会显示当前楼层和阅读进度。手动滚动可暂停，点击「继续」即可接着读。
