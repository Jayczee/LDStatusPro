# LDStatus Pro

本仓库是 LDStatus Pro 的 fork。原版功能和使用文档请见[原仓库 caigg188/LDStatusPro](https://github.com/caigg188/LDStatusPro)。

### v3.9.0.12

本 fork 基于此版本新增了**自动阅读帖子回复**功能，代码在[自动阅读分支](https://github.com/Jayczee/LDStatusPro/tree/feat/topic-reply-reader)。打开帖子后，脚本默认每 5 秒在后台读取 3 条回复。你可以照常滚动或写回复，在面板查看后台进度、暂停或继续。间隔可选 3、5、10、20、30、60 秒，每批可选 1、3 或 5 条，两项设置都会保存。论坛已读状态由站点自行统计。
