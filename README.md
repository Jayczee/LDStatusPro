### v3.9.0.17-Jayczee

打开帖子后，脚本默认每 5 秒在后台读取 3 条回复。你可以照常滚动或写回复，在面板查看后台进度、暂停或继续。间隔可选 3、5、10、20、30、60 秒，每批可选 1、3 或 5 条，两项设置都会保存。论坛已读状态由站点自行统计。
